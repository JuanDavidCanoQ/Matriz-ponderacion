# Matriz de Ponderación · Weighted Decision Matrix

**Español** · [English](#english)

Herramienta web para evaluar y priorizar opciones con criterios ponderados.

**En línea:** https://matriz-ponderacion.vercel.app

## Qué hace
- Criterios y pesos editables, con redistribución automática de los pesos.
- Puntaje y ranking en vivo, con conclusiones generadas automáticamente.
- Escenarios predefinidos para empezar rápido.
- Exporta a PNG y Excel; disponible en español e inglés.

## Cómo está hecho
Un solo archivo `index.html` con HTML, CSS y JavaScript, sin frameworks ni proceso de compilación. Para usarla en local basta con abrir el archivo en el navegador.

## English

A web tool to evaluate and prioritize options using weighted criteria.

**Live:** https://matriz-ponderacion.vercel.app

### What it does
- Editable criteria and weights, with automatic weight redistribution.
- Live scoring and ranking, with automatically generated conclusions.
- Preset scenarios for a quick start.
- PNG and Excel export; available in Spanish and English.

### How it's built
A single `index.html` file with HTML, CSS and JavaScript, no frameworks and no build step. To run it locally, just open the file in a browser.
